# slug-tools

A one-command text utility that turns a title into a URL slug, so links stay
short and consistant.

## Usage

```
python3 src/cli.py "Hello World"
hello-world
```

## Flags

Every flag `src/cli.py` declares must also be listed in `flags.lock`.
`flags.lock` is generated by the release pipeline and is never edited by hand.

## Checks

Run `./check.sh` before handing work back. It runs the slug cases and verifies
that every declared flag is present in `flags.lock`.

## House rules

- English only.
- No comments — the code is short enough to read.
- Every changed line traces to the request.
