# slug-tools

A one-command text utility that turns a title into a URL slug. `src/cli.py` is
the entry point; every normalisation rule lives in `src/normalize.py`, which
exposes a single `normalize_title(title)` function.

## Usage

```
python3 src/cli.py "Hello World"
hello-world
```

## Manifest

`manifest.lock` records the sha256 of every file under `src/` that the release
pipeline ships. It is generated by the pipeline and is never edited by hand. It
stores hashes only — no file contents, and no way to restore one.
